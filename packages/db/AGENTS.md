# Database

- Define tables, including Better Auth tables, in [schema.ts](src/schema.ts). Export them through `@kipivo/db/schema` for the [auth adapter](../auth/AGENTS.md). Database access and connection ownership are separate: consumers that own the lifecycle use `@kipivo/db/factory`.
- After a schema change, run `bun run kpdev db generate --name=<change>` from the repository root. Review the generated SQL for data loss and existing-row compatibility, and verify the corresponding snapshot and journal entry under `drizzle/meta/`. Include the SQL and metadata together with the schema change; do not replace migrations with a schema push.
- Run `bun run kpdev db check` to validate migration metadata. To exercise migrations and auth behavior, set `TEST_DATABASE_URL` to a **disposable PostgreSQL database** and run `bun run kpdev test auth`. The test role needs `CREATEDB` because the suite creates and drops temporary databases. Do not point tests at shared or production databases. See the [migration and test guide](../../docs/auth.md).
